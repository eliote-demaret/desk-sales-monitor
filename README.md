# Moniteur du sales dérivés

🔗 **Application en ligne :** https://desk-sales-monitor-7ypxmnwoxcucp4grphyqwy.streamlit.app/

Une application qui lit les **données de marché en direct** (actions, options, change) et propose,
comme le ferait un **sales en salle de marché**, des **idées de produits dérivés adaptées à chaque type de client** :
le produit, les chiffres, les risques et le pitch.

**Exemples de raisonnement :**
- Options chères → proposer un produit de rendement (reverse convertible)
- Options bon marché → proposer de la protection (put, capital garanti)
- Action proche de ses plus hauts → sécuriser la plus-value (collar)
